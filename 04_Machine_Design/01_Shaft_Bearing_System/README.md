Shaft + Bearing System

A small mechanical design and FEA study of a shaft supported by rolling-element bearings.

Objective

Understand how loads travel through a shaft-bearing system and connect:

Applied Loads → Bearing Reactions → Shaft Stress → Deformation → Bearing Loads → FEA

Engineering Questions

- How are bearing reactions calculated?
- How does the shaft diameter affect stress and deformation?
- How does torque affect the shaft?
- What loads act on the bearings?
- How does bearing position affect the system?
- How can hand calculations be verified using FEA?
- Why do hand calculations and FEA results differ?

System

A simplified shaft supported by two bearings will be studied under representative mechanical loading.

The system will initially be kept simple so that each calculation can be understood and verified.
